## 1. الأخطاء المكتشفة (موثّقة بالأدلة)

### 1.1 خطأ حرج — `cash-300` غير معرّف في `@theme` لكنه مستخدم 12 مرة

`src/index.css` يعرّف: `cash-50, 100, 200, 400, 500, 600, 700, 800, 900`.
اللون **`cash-300` غير موجود**، لكنه مستخدم في 12 موضعاً. في Tailwind v4 الـ utility غير المعرّف **لا يُولَّد إطلاقاً**، فالعنصر يرث لون الأب.

دليل من مخرجات البناء:

```
dist/assets/index-BpDdt5GK.css
  contains 'cash-300' → False
  contains '93c5fd'   → False
```

## 4. فجوات الجودة والوصولية و SEO

| البند | الحالة الحالية |

| `:focus-visible` | **0 استخدام** → حلقة التركيز الافتراضية غير متناسقة بين المتصفحات |
