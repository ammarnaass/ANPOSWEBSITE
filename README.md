# AN POS WEBSITE 🚀

الموقع الرسمي التعريفي لنظام نقاط البيع وإدارة المتاجر **AN POS** (المتوفر لسطح المكتب والهاتف).

---

## 📌 نبذة عن المشروع
موقع حديث مصمم بدقة وفق معايير **Stitch POS Minimal Design** لدعم التجار، المحلات، ونقاط البيع في الجزائر والعالم العربي.
- **التصميم الطباعي**: يعتمد خط `Cairo` العربي فائق الوضوح و `IBM Plex Sans Arabic`.
- **التقنيات**: React 19، Vite، Tailwind CSS v4، TypeScript.
- **التوافق**: متوافق تماماً مع الهواتف الذكية والشاشات الكبيرة مع دعم كامل لاتجاه RTL.

---

## 🛠️ التقنيات المستخدمة
- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Typography**: [Google Fonts Cairo & IBM Plex Sans Arabic](https://fonts.google.com/)
- **Icons**: [Material Symbols Outlined](https://fonts.google.com/icons)
- **Language**: TypeScript

---

## 🚀 التشغيل والتطوير المحلي

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
